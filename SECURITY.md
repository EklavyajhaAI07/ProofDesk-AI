# Security Policy

## Supported Versions

Only the latest version of MeDo-ProofDesk is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.1   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within MeDo-ProofDesk, please do not disclose it publicly. Instead, follow these steps:

1. **Email us**: Send a detailed report to security@example.com (replace with your actual security contact).
2. **Details**: Include a description of the vulnerability, steps to reproduce, and potential impact.
3. **Response**: We will acknowledge your report within 48 hours and provide a timeline for resolution.

Thank you for helping keep MeDo-ProofDesk secure!
